# SUDOLLAMAX-ULTIMATE-INSTALLATION-LANCEUR-UNIVERSEL
Sudollamax is a universal model launcher that replaces Ollama. It supports all major AI engines: Hugging Face, TensorFlow, PyTorch, ONNX, TensorRT, JAX, and Ollama (GGUF). One tool to run any model, anywhere. Auto-detects model type, handles dependencies, and works with GPU or CPU. Built for developers, researchers, and curious minds.
